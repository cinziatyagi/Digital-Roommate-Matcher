# Project Statement – Digital Roommate Matcher

## Problem Statement

Finding a suitable roommate manually can be difficult because students may have different sleeping schedules, study habits, cleanliness preferences, noise preferences, food choices, and other lifestyle preferences.

The Digital Roommate Matcher is a Java-based application that helps students find compatible roommates by collecting their preferences and calculating compatibility scores between students.

## Project Scope

The project focuses on:

- Registering student profiles.
- Storing and managing student information.
- Searching, updating, and deleting student profiles.
- Comparing student preferences.
- Calculating roommate compatibility scores.
- Displaying suitable roommate matches with compatibility categories.

The project uses a text file for persistent data storage and does not require an external database.

## Target Users

The primary target users are:

- College and university students looking for compatible roommates.
- Hostel students who want to compare lifestyle preferences before sharing a room.

## High-Level Features

1. **Student Profile Management**
   - Register a new student.
   - View all students.
   - Search student profiles.
   - Update student information.
   - Delete student profiles.

2. **Roommate Matching**
   - Compare lifestyle and room preferences.
   - Calculate a compatibility score.
   - Identify compatible and different preference areas.
   - Display matches in descending order of compatibility.

3. **Student Information Management**
   - View complete student details.
   - Store student records in a text file.
   - Load saved records when the application starts.

4. **Input Validation**
   - Validate numeric inputs.
   - Prevent empty profile fields.
   - Validate menu choices.
   - Handle invalid or incomplete stored records.
